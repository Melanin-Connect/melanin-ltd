# Melanin Connect

Marketing website for [Melanin Connect](https://melaninconnect.xyz/): AI and blockchain solutions for business growth.

## Stack

- [TanStack Start](https://tanstack.com/start) with file-based routing, server-side rendered
- React 19 and TypeScript
- Tailwind CSS v4
- Vite, with Nitro producing the Vercel deployment output
- Vitest for tests

## Getting started

Requires Node.js 20+ and [pnpm](https://pnpm.io/).

```sh
pnpm install
pnpm dev        # http://localhost:8080
```

## Scripts

| Command          | What it does                           |
| ---------------- | -------------------------------------- |
| `pnpm dev`       | Start the dev server on port 8080      |
| `pnpm build`     | Production build into `.vercel/output` |
| `pnpm preview`   | Preview the production build locally   |
| `pnpm lint`      | Run ESLint                             |
| `pnpm typecheck` | Type-check with `tsc`                  |
| `pnpm test`      | Run the Vitest suite                   |
| `pnpm format`    | Format the codebase with Prettier      |

## Project structure

```
public/
  images/            Site photography and the logo
  favicon.ico        Browser icons and the social share image
src/
  components/        Header, footer, page sections and icons
  lib/site.ts        Contact details, navigation links, image paths, page <head> helper
  routes/            One file per page (/, /about-us, /services, /contact-us, /privacy)
  styles.css         Tailwind entry: brand tokens, animations and base styles
```

`src/routeTree.gen.ts` is generated by the TanStack Router plugin. Don't edit it by hand.

## Updating content

- **Images.** Replace a file in `public/images/` with one of the same name: `logo.png`, `hero-home.jpg`, `hero-services.jpg`, `card-1.jpg` to `card-4.jpg`.
- **Contact details.** Email, phone, hours and address live in `src/lib/site.ts`.
- **Brand colour.** `--color-brand` in `src/styles.css` drives every pink accent.

## Deploying

The build targets Vercel. Import the repository in Vercel and keep the defaults: install `pnpm install`, build `pnpm build`. Nitro writes the Vercel Build Output to `.vercel/output`.

The contact form is visual only. Connect a form or email service before relying on it.
